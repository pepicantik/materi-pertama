Bagian 1

HTML: Fondasi Halaman Web

HyperText Markup Language adalah bahasa markup untuk menyusun struktur dan isi halaman web.

📖

Pengertian dan Fungsi

HTML menandai jenis konten seperti judul, paragraf, gambar, tautan, dan form memakai tag. Browser mengubahnya menjadi DOM lalu menampilkannya di layar.

🧱

Struktur Dasar Dokumen

Setiap halaman diawali <!DOCTYPE html>, lalu elemen html, head untuk informasi halaman, dan body untuk konten yang terlihat.

🏷️

Semantic HTML

Pilih elemen berdasarkan fungsinya: header, nav, main, section, article, dan footer.

📝

Form dan Validasi

Atribut seperti required, minlength, pattern, dan type memvalidasi input langsung di browser.

♿

Accessibility

label, alt, dan atribut aria-* membuat halaman bisa dipakai screen reader dan navigasi keyboard.

🔍

SEO Dasar

Metadata di head seperti title, description, dan Open Graph membantu halaman dipahami mesin pencari.

Struktur Dokumen

Kerangka minimal yang wajib ada

Kerangka ini memastikan browser membaca halaman dengan benar, menampilkan bahasa yang tepat, dan menyesuaikan layout di layar HP.

  • lang="id" menandai bahasa halaman
  • charset="UTF-8" agar karakter tampil benar
  • viewport untuk tampilan mobile
  • title muncul di tab dan hasil pencarian
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width,
        initial-scale=1.0">
  <title>Halaman Pertamaku</title>
</head>
<body>
  <h1>Halo, Dunia!</h1>
</body>
</html>
<header>
<nav>
<main> <section> & <article>
<footer>
Semantic HTML

Elemen yang punya makna

Semantic HTML membuat struktur mudah dibaca, dinavigasi screen reader, dan dipahami mesin pencari.

  • header dan nav untuk kepala halaman dan navigasi
  • main berisi konten utama (satu per halaman)
  • section mengelompokkan konten sejenis
  • article untuk konten yang berdiri sendiri
  • footer untuk bagian penutup
Bagian 2

CSS: Mengatur Tampilan

Cascading Style Sheets memisahkan tampilan dari struktur, sehingga kode lebih rapi dan mudah dirawat.

🎨

Pengertian dan Fungsi

CSS mengatur warna, font, jarak, tata letak, hingga animasi. Bisa ditulis inline, internal, atau eksternal (disarankan).

🖌️

Styling Dasar

Properti seperti color, font-family, background, dan variabel var(--nama) menjaga tampilan konsisten.

🎯

Selector dan Specificity

Selector memilih elemen, specificity menentukan aturan mana yang menang ketika terjadi bentrok.

📦

Box Model

Setiap elemen adalah kotak berlapis: content, padding, border, dan margin.

🧩

Flexbox dan Grid

Flexbox untuk layout satu arah, Grid untuk layout dua arah. Keduanya sering dipakai bersama.

✨

Transition dan Hover

Perubahan tampilan yang halus saat kursor diarahkan ke elemen. Coba arahkan kursor ke kartu ini.

Specificity: siapa yang menang?

Bobot dihitung dari inline, ID, class, lalu elemen. Bobot tertinggi menang, bila sama maka yang ditulis terakhir menang.
